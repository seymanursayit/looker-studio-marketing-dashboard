# Looker Studio Marketing Dashboard

## Overview

This project focuses on analyzing and visualizing digital marketing campaign performance using Google Looker Studio and PostgreSQL.

An interactive dashboard was created to monitor advertising spend, campaign activity, and marketing performance metrics across Facebook Ads and Google Ads.

## Objectives

- Connect PostgreSQL as a data source in Looker Studio.
- Create calculated fields for key marketing metrics.
- Visualize monthly advertising spend and ROMI.
- Track the number of active marketing campaigns.
- Compare campaign performance using a heatmap table.
- Add interactive campaign and date filters.

## Dashboard Visualizations

1. **Combo Chart:** Monthly Ad Spend and ROMI.
2. **Line Chart:** Monthly Active Campaign Count.
3. **Heatmap Table:** Campaign-level comparison of Ad Spend, ROMI, CTR, CPM, and CPC.

## Key Metrics

- Ad Spend
- CPC (Cost Per Click)
- CPM (Cost Per 1,000 Impressions)
- CTR (Click-Through Rate)
- ROMI (Return on Marketing Investment)
